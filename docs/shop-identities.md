werden; die Texte nennen deshalb keine Motive, nur Haltung, Qualität und Service. Die Shops
unterscheiden sich im Ton.

Vorbild: die Shop-Bios der umsatzstärksten Print-Shops auf Etsy (API-Scan von 933 Shops, z. B.
KelseyMDesigns 48k Sales, BelleBotanica 28k, BrightBlueStar 23k, PrintHerosShop 16k): kurze
herzliche Begrüßung, was man macht und warum, kurz die Qualität, Einladung zum Schreiben, Vorname.

## Was wo eingetragen wird

| Feld                         | Wo auf Etsy                                         | Per API? |
| ---------------------------- | --------------------------------------------------- | -------- |
| Shopname                     | Shop-Manager → Einstellungen → Info & Erscheinungsbild | nein  |
| Shop title                   | Info & Erscheinungsbild                             | ja       |
| Shop-Icon (Logo, ≥ 500 px)   | Info & Erscheinungsbild                             | nein     |
| Banner (3360 × 840)          | Shop bearbeiten → Banner („Big banner“)             | nein     |
| Announcement                 | Shop bearbeiten                                     | ja       |
| Message to buyers            | Info & Erscheinungsbild                             | ja       |
| About (Headline, Story)      | Shop bearbeiten → About                             | nein     |
| Owner-Foto und Bio           | Shop bearbeiten → Shop-Mitglieder                   | nein     |
| Verkäuferangaben / Impressum | Einstellungen → Rechtliches / Verkäuferangaben      | nein     |
| Privacy policy, FAQ          | Shop-Richtlinien                                    | nein     |
| Rückgabe-Richtlinie          | Shop-Richtlinien                                    | ja       |
| Versandprofil, Bearbeitungszeit | Einstellungen → Versand                          | ja       |
| Shop sections                | Listings → Sections                                 | ja       |

Etsy verlangt laut Creativity Standards, dass mit KI erstellte Designs **in der
Listing-Beschreibung** offengelegt werden. Die About-Texte oben sagen es; die
Beschreibungsvorlage der Uploads (`src/lib/uploads/description.ts`) tut es noch nicht.

## Versand

Ziel: Herkunft USA, 1–3 Tage Bearbeitung, kostenlos, kurze aber haltbare Laufzeiten
(`scratchpad/shipping-setup.mjs --apply` legt das in allen drei Shops an):

| Ziel                 | Transit   | Gesamt mit Bearbeitung | Gelato real (inkl. Produktion) |
| -------------------- | --------- | ---------------------- | ------------------------------ |
| USA                  | 3–6 Tage  | 4–9                    | 5–9                            |
| Kanada               | 3–6       | 4–9                    | 4                              |
| UK                   | 2–5       | 3–8                    | 4–6                            |
| EU                   | 2–5       | 3–8                    | 3–5                            |
| Schweiz, Norwegen    | 3–7       | 4–10                   | –                              |
| Australien           | 2–5       | 3–8                    | 3–5                            |
| Neuseeland           | 3–7       | 4–10                   | –                              |
| Japan, Singapur      | 4–8       | 5–11                   | –                              |
| Rest der Welt        | 5–10      | 6–13                   | –                              |

Danach: die neuen Profil-IDs als `listing.shippingProfileId` / `readinessStateId` je Konto
setzen und die zwei Live-Listings umhängen. In Gelato (Stores → Edit store details →
Shipping) die Gelato-Versandprofile abschalten, sonst hängt Gelato beim Veröffentlichen sein
eigenes Profil an (der Post-Check der Pipeline setzt es zwar zurück, aber erst danach).
